# 천천히 · 저속노화 루틴 (웹앱 MVP)

## GitHub Pages로 배포
1. GitHub에서 새 저장소 생성 (예: `slow-aging`)
2. 이 폴더의 파일 4개(`index.html`, `manifest.json`, `icon-512.png`, `apple-touch-icon.png`)를 저장소 루트에 업로드 — "Add file → Upload files"
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
4. 1–2분 뒤 `https://<아이디>.github.io/slow-aging/` 접속

## 폰에 설치
- iPhone(Safari): 공유 버튼 → "홈 화면에 추가"
- Android(Chrome): 메뉴 → "홈 화면에 추가"

## 데이터
- 기록은 이 기기 브라우저(localStorage)에만 저장됩니다. 서버 전송 없음.
- Safari 방문 기록·웹사이트 데이터를 지우면 기록도 사라집니다. 내 루틴 → 내보내기로 백업하세요.
- 같은 주소라도 Safari와 홈 화면 앱은 저장소가 분리될 수 있습니다. 홈 화면 앱으로 쓰는 것을 권장합니다.

## 참고
- 의료 조언이 아닙니다. 추천 규칙은 검증 전 가설입니다.
- 음주·흡연 근거 4편의 PMID는 사용 전 확인이 필요합니다.
